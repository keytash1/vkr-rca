# Локальные инструкции расследования

`basic-investigation.json` — собственные общие проверочные рекомендации RCA
Workbench. Они не содержат разметки, ответов контрольных инцидентов и материалов
работодателя. Это не описание архитектуры Petclinic или конкретной компании.
Здесь намеренно нет исполняемых команд и обязательных числовых порогов.

Администратор явно подключает файл параметром `--runbook-corpus`. Доступ
ограничен `projects`, максимальным размером/числом разделов и точной схемой.
`external_transmission_approved=true` — явная декларация оператора о разрешении
передавать этот текст настроенному внешнему провайдеру; отсутствие разрешения
отклоняет подключение. Поле не заменяет согласование реальных прав на материал.
Корпус загружается на старте, версия и SHA сохраняются в provenance задания.

Инструмент получает только выбранную тему и одобренные разделы проекта. Никаких
путей, URL, открытого веб-поиска или чтения произвольных документов из LLM нет.
Содержимое считается недоверенной рекомендацией; оно не меняет системные права.
Указанный в нём совет не является фактом инцидента или уже выполненной проверкой.

Семантика наблюдений сверяется с первичными руководствами:

- [Prometheus: metric types](https://prometheus.io/docs/concepts/metric_types/)
  и [query functions](https://prometheus.io/docs/prometheus/latest/querying/functions/).
- [OpenTelemetry: traces](https://opentelemetry.io/docs/concepts/signals/traces/)
  и [sampling](https://opentelemetry.io/docs/concepts/sampling/).

При изменении корпуса создавайте новую версию и повторяйте development-проверки.
Не добавляйте сведения о причинах закрытого теста в доступные ему runbooks.
