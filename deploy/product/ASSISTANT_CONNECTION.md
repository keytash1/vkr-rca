# Подключение необязательного помощника

Основной анализ, первичные наблюдения и карточки работают без внешней модели.
Подключение выполняет владелец установки; подписка разработчика не передаётся
пользователям продукта.

## Авторизация

```bash
python3 -m venv .venv-assistant
.venv-assistant/bin/python -m pip install -r deploy/product/requirements-assistant.txt
.venv-assistant/bin/python cmd/thesis_demo/assistant_auth.py \
  --state-dir "$PWD/.rca-private/assistant" --port 18222
```

Откройте `http://127.0.0.1:18222/` и пройдите официальный вход в собственный
аккаунт. Проверьте назначение разрешения на настоящей странице OpenAI.
Не передавайте пароль/коды/токены разработчику или в чат и не копируйте чужую
авторизацию. Flow не извлекает учётные данные Codex или историю разговоров.
Вход сам по себе не отправляет телеметрию. Доступность способа подключения и
модели зависит от аккаунта и действующих условий провайдера.

Credentials хранятся локально: каталог 0700, файлы 0600, вне Git и образа.
Refresh атомарный и сериализуется локальным lock. Отзыв разрешения выполняется
в настройках подключений ChatGPT. Не используйте этот каталог как общий
распределённый credential store для независимых пользователей.

## Включение на конкретном проекте

Оператор сначала разрешает внешнюю передачу агрегатов выбранного проекта и
текста вопроса. Произвольные теги, URL источников и исходные имена сервисов
не передаются. Псевдонимизация не является гарантией анонимности: секреты и
неразрешённые данные нельзя вводить в вопрос. Ручная карточка не отправляется.

```bash
PYTHONPATH=ml:cmd/thesis_demo .venv/bin/python cmd/thesis_demo/server.py \
  --root . --port 18100 --workspace-dir .rca-private/workspace \
  --assistant-python "$PWD/.venv-assistant/bin/python" \
  --assistant-state-dir "$PWD/.rca-private/assistant" \
  --assistant-model gpt-6.1-sol --allow-assistant-profile my-system \
  --runbook-corpus deploy/runbooks/basic-investigation.json
```

Общий учебный корпус по умолчанию ограничен другими project IDs. Для своей
установки подготовьте отдельную копию: проверьте применимость текста, задайте
разрешённые `projects`, уникальные ID/версии/разделы и только затем подтвердите
`external_transmission_approved`. Одно это поле не создаёт права передавать
документы работодателя. Корпоративные материалы в комплект не входят.

Для локальной Python-установки прогрейте публичный словарь отдельно:

```bash
.venv-assistant/bin/python -c 'import tiktoken; tiktoken.get_encoding("o200k_base")'
```

Worker проверяет SHA словаря и не скачивает его во время задания. Без него
работает более строгая байтовая оценка; большой вход может быть отклонён до
вызова модели. Optional-контейнер включает проверенный публичный словарь.

## Что делает помощник

Панель формирует гипотезы и следующие проверки по сохранённому снимку. Tools
читают только разрешённые агрегаты, baseline, временные группы, примеры спанов,
наблюдаемые связи и scoped runbooks. Они не получают shell, произвольный URL,
PromQL, файл или право изменять сервисы. Рекомендация runbook не становится
наблюдаемым фактом текущего инцидента. Рейтинг продолжает вычислять ML-модель.

Одна задача выполняется, одна ожидает. Есть общий deadline 60 секунд, лимиты
обращений к модели/tools и учёт фактического usage. Локальная оценка ввода не
равна invoice или гарантированному жёсткому пределу удалённой генерации.
Неизвестный расход не записывается нулём. Отмена прекращает локальный worker;
прекращение удалённой генерации может остаться неизвестным. Автопокупок,
автопополнения и скрытого платного API-fallback в продукте нет.

При отказе используйте исходные наблюдения и детерминированные проверки.
Структурная проверка JSON и существующая ссылка не гарантируют истинности
интерпретации. Проверку гипотезы и итоговый вывод фиксирует инженер.

Основание подключения: [официальный Sign in with ChatGPT](https://developers.openai.com/siwc/token-sharing-open-source/sign-in)
и [ограничения preview](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations).
