# Выпуск RCA Workbench 1.0 — границы проверки

Приложение поддержки расследования для ВКР: система и интервал → сбор
Prometheus/Jaeger → фиксированный ML-рейтинг → наблюдения → карточка
расследования и меры. Обычная работа инженера не требует подготовки JSON.
Первичное подключение источников и здорового состояния выполняет интегратор.

Проверены два локальных подключения к настоящим источникам: собственные
Go-сервисы и внешнее приложение Spring Petclinic. Проверены подготовка и
откат baseline, основной запрос, отказы источников и восстановление, сохранение
истории, конфликт редакций, экспорт, миграция и перезапуск. Чистый состав
не требует исследовательского корпуса или экспериментального стенда.

В окончательном интерфейсе предусмотрены прямые переходы к расследованию и
истории. Дополнительные поля раскрываются по запросу; при проверке эффекта
меры её план и результат раскрываются автоматически. Сведения о неполноте,
ошибках и передаче данных провайдеру не скрываются этим упрощением.

Необязательный помощник работает через отдельное разрешённое подключение
провайдера. Он читает выбранный снимок и ограниченные инструкции, предлагает
гипотезы и проверки; не выполняет команды и не меняет рейтинг. Проверены
контракты, ограничения доступа, 20 реальных предъявлений тестовых инъекций
и последующие уточнения. Отказ LLM оставляет базовую диагностику доступной.

Расширенный сравнительный прогон C/D/E операционно остановлен при сокращении
объёма работы: 184 сохранённых исхода из 270 назначений, ещё одна начатая
попытка без результата, 85 не отправлены. Сохранены 179 завершённых ответов,
4 budget partial, один обрыв и дополнительный UNKNOWN остановленной попытки.
Эти данные **не подтверждают прохождение полного сравнительного протокола**,
превосходство LLM/ML-подсказки или экономию времени инженера. Содержательный
разбор исполнителем Codex не является независимым человеческим пилотом.
Предложения профилактических мер не гарантируют предотвращения повторов.

Native-запуск с собственным разрешённым подключением LLM проверен.
Docker workspace без LLM проверен с приватным named volume и перезапусками.
Контейнерное подключение учётных данных требует корректного UID/mount;
конкретная передача credentials через Colima bind не считается принятой.
Не ослабляйте права и не копируйте токены для обхода этих проверок.

Это однопользовательский локальный инструмент, не публичный многопользовательский
сервис. Для нового проекта проверяются смысл метрик, единицы, алиасы,
полнота и сроки хранения телеметрии. Исполнимое подключение не гарантирует
точности ранжирования. Балл ML — не вероятность и не доказанная первопричина.

Исследовательская история и протоколы: https://github.com/keytash1/vkr-rca .

Логи, события среды и история изменений относятся к следующей итерации;
не являются скрытыми зависимостями данного выпуска.
