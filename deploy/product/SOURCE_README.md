# RCA Workbench

Локальное приложение поддержки расследования инцидентов в микросервисной
системе. Инженер выбирает подключённую систему и интервал, получает полный
порядок проверки сервисов и открывает подтверждающие наблюдения. Подготовка
JSON-файла для обычного анализа не нужна.

Проверенный состав выпуска и границы экспериментальных выводов описаны в
[RELEASE.md](RELEASE.md). Необязательный помощник не заменяет проверку
гипотез инженером; сравнительное преимущество LLM не заявляется.

## Возможности

- Чтение метрик Prometheus и трасс Jaeger; нормализация через профиль проекта.
- Полный ML-рейтинг, реальные значения метрик, временные графики, длительности
  операций и наблюдаемые связи с явными сведениями о неполноте данных.
- Сохранённые снимки, история расследований, хронология, гипотезы и меры
  с ответственными, сроками и результатами проверки.
- Необязательный LLM-помощник: гипотезы, альтернативы и следующие проверки
  со ссылками на наблюдения; ограниченные read-only инструменты и scoped runbooks.
- Работа без LLM и внешней передачи данных. Отказ провайдера не мешает рейтингу
  и работе инженера с первичными наблюдениями.

## Быстрый запуск

Нужны Python 3.12+, доступ к источникам телеметрии и профиль вашей системы.
Проверенные платформы, системные зависимости и ограничения native-установки
указаны в [матрице совместимости](deploy/product/COMPATIBILITY.md).
Профиль и здоровое базовое состояние подготавливает интегратор один раз:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r deploy/product/requirements.txt
```

Следуйте [подключению системы](docs/ONBOARDING.md): инвентарь и смысл метрик →
проверка источников → здоровый период → подготовка → явная активация.
Шаблон `deploy/profiles/examples/new-system.template.json` требует реальных
имён, запросов и адресов; это не готовое подключение к произвольному проекту.

После активации профиля:

```bash
PYTHONPATH=ml:cmd/thesis_demo .venv/bin/python cmd/thesis_demo/server.py \
  --root . --host 127.0.0.1 --port 18100 \
  --workspace-dir .rca-private/workspace
```

Откройте `http://127.0.0.1:18100/`. Основной путь — система, интервал известного
инцидента, рейтинг, наблюдения, карточка. Это поддержка выбора следующих
проверок, а не детектор инцидентов или автоматическое доказательство причины.

## Поставка и API

[Архитектурные контракты](docs/ARCHITECTURE.md) описывают границы модулей,
состояния неполноты, внешнюю передачу и основания выбора локального хранения.

Контейнерные targets `runtime`, `workspace`, `assistant` разделяют минимальный
анализ, локальную историю и optional-провайдера. Настройки, приватные volumes,
обновление/откат описаны в [руководстве workspace](deploy/product/WORKSPACE.md).
Контейнеру не нужен Docker socket. Порт публикуется на loopback; публичный
многопользовательский доступ встроенный сервер не предоставляет.

Машинный контракт доступен на `/api/openapi.json`. Основной read-only запрос:

```json
{"profile_id":"my-system","start_unix":1700000000,"end_unix":1700000300}
```

`POST /api/analyze` возвращает всех кандидатов, сведения об источниках и ID
снимка. `/api/v2/analyses/{analysis_id}/evidence` возвращает каталог фактов.
Рабочее пространство защищает изменяющие запросы session cookie и CSRF;
не передавайте туда URL/запросы к источникам — они задаются интегратором.
`GET /healthz` проверяет готовность ядра, не доступность телеметрии.

Подключение LLM выполняется отдельно по [инструкции](docs/ASSISTANT_CONNECTION.md).
Нужны собственное разрешённое подключение провайдера и согласие на передачу
агрегатов конкретного проекта. Аккаунт, подписка и корпоративные материалы
не входят в продукт. ML-рейтинг остаётся неизменным независимо от ответа LLM.

## Разработка и границы проверки

```bash
.venv/bin/python -m pip install -r requirements-dev.txt \
  -r deploy/product/requirements-assistant.txt
PYTHONPATH=ml:cmd/thesis_demo .venv/bin/python -m unittest discover \
  -s cmd/thesis_demo -p 'test_*.py' -q
```

Тестовые примеры в этом репозитории искусственные и самодостаточные; inference
провайдера при тестировании не вызывается. Научный корпус, fault-контроллеры,
gold и старые DOCX остаются в отдельном исследовательском репозитории.
Интегратор проверяет реальные метки, единицы, алиасы, coverage, задержки доставки
и ограничения retention на своей системе. Балл модели не является вероятностью;
перенос исполнения не гарантирует точность диагноза на новом проекте.

Оригинальный продуктовый код и локально обученные параметры — Apache-2.0.
Состав и происхождение компонентов: [NOTICE](NOTICE),
[THIRD_PARTY.md](THIRD_PARTY.md), [THIRD_PARTY_NOTICES](THIRD_PARTY_NOTICES).
