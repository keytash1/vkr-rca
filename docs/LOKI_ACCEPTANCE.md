# Ограниченная приёмка контекста — 19.10.2026

Настоящий Loki 3.7.8, официальный darwin/arm64 binary, отдельный loopback
процесс и filesystem. Архив сверён с официальным SHA-256:
`95d830437482aba989a7d7a65be3c618a67a6e46f6e614544cc4b9ce09f499a1`.
Docker не запускался, системная служба не устанавливалась.

Учебное приложение выполнило реальные HTTP-запросы к зависимости, записало
возникшие исключения/статусы и отправило записи в Loki через push API.
Workbench прочитал их через настоящий query_range; выбранные поля и SHA-256
сверены с записями приложения. Controller truth не отправлялась источнику.

В итоговом инженерном пилоте шесть отказов и четыре контроля. Внешний ответ
во всех отказах — 503, внутри наблюдались HTTPError/403, ConnectionRefusedError
и TimeoutError. Без журналов общий 503 не различает отказ доступа и соединения;
журнал даёт проверку прав либо адреса/порта. Таймаут частично виден уже по
длительности: не засчитывается как безусловный выигрыш контекста.

Посторонний релиз исключён service scope, пустая выборка не названа здоровьем,
лимит обозначен усечением, недоступность источника — недоступностью. Проверен
точный end-exclusive запрос с наносекундной границей. Это технический пилот,
не слепой эксперимент, не новая точность ранжировщика и не исследование MTTR.

Две первоначальные попытки обнаружили дефекты измерительного скрипта:
пятимиллисекундный padding захватил соседний случай; два последовательных
чтения часов создали нулевой интервал пустого контроля. Эти попытки сохранены
как ошибки протокола; не объявлены успешными. Исправления касались только
границ/сохранения измерений, не приложения, модели или выбора красивых ответов.

Продуктовый HTTP-путь отдельно проверен с настоящим Loki и явно искусственными
источниками метрик/трассировок. Рейтинг и SHA-256 входа совпали с теми же данными
без контекста. Снимок содержит новые факты; безопасная проекция инструментов
помощника содержит только разрешённые категории. Провайдер не вызывался.

После остановки настоящего Loki повторный запрос вернул HTTP 200 с тем же
рейтингом и SHA входа. Новый контекст — unavailable, прежний успешный снимок
не изменился и не был выдан как новое чтение. Браузерный блок содержит короткие
проверки; поля записей и сведения об источнике раскрываются отдельно.

Полные локальные протоколы хранятся в исследовательском репозитории:
`docs/product-acceptance/iteration-2/LOKI_PILOT_PROTOCOL.md`,
`loki-live-1`, `loki-live-2`, `loki-live-final`, `loki-product`.
Перенос на произвольную компанию и сокращение трудозатрат этими данными
не подтверждаются. Продвинута только необязательная ограниченная функция.
