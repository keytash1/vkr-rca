18.10.2026. Этот короткий список имеет приоритет над историческими открытыми
пунктами больших планов. Основание: сверка продуктовых требований исходного
VKR_RCA_MASTER_ROADMAP_FINAL (§1, M12.2, M13-D, M15) и последующего R2-плана,
текущий код и прямое требование пользователя сократить лишние движения.

## Что входит

- [x] Система + интервал → реальные Prometheus/Jaeger → фиксированный полный
  рейтинг и наблюдения. JSON не требуется от инженера.
- [x] Подключение интегратором без изменения Python: профиль, inspect,
  healthy prepare, явная активация и откат. Это пошаговый CLI, не обещанный
  универсальный автоматический веб-мастер; смысл метрик подтверждает интегратор.
- [x] Графики, базовое состояние, примеры трасс и ссылки на источники;
  пропуски/неактивность/отказ источника не подменены нормальным нулём.
- [x] Optional LLM: вопросы/уточнения, альтернативы, ограниченные чтения
  выбранного снимка и runbooks; без изменения ранга и применения исправлений.
- [x] Карточки: симптомы, влияние, хронология, несколько гипотез, вывод инженера,
  меры/владелец/срок/план и результат проверки; история/фильтры/JSON/Markdown.
- [x] Закончить один компактный UI-проход: прямой переход к расследованию
  и истории; дополнительные поля и пояснения раскрываются по запросу.
  Не скрывать важные предупреждения о данных/ошибках/передаче провайдеру.
- [x] Опубликовать чистый продукт, проверить clone и один удалённый CI,
  согласовать ссылки исследовательской истории/main/M14 с итоговой поставкой.
- [x] Сохранить краткий паспорт версии/запуска/ограничений и показать готовый UI.

## Достаточная проверка

Ранее проверенное не прогоняется заново без изменения соответствующих файлов.
Для финальных UI-правок — существующие UI-регрессии, два точечных сценария
перехода/раскрытия и один просмотр в браузере. Для поставки — один CI и clone.
Никаких новых LLM-генераций и полного дочитывания остановленного сравнения.
Сравнительный результат остаётся INCONCLUSIVE; безопасность optional-пути и
работоспособность базовой диагностики оцениваются отдельно.
