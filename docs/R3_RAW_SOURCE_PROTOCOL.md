## Первый gate: происхождение и формат

Источник: Zenodo record 17105974, CC BY 4.0 по metadata записи.
`rcabench-absolute_anomaly.tar.gz`: 13 444 974 981 bytes,
официальный MD5 `96d32ae290e06be7d4e251be02b36cb8`.
Не приравниваем к ops-lite: это отдельный авторский архив; происхождение и
пересечения случаев нужно установить, не объявлять зеркала независимыми.

Сначала один raw datapack из начала tar-потока, только schema discovery:
не более 128 MiB сетевых данных, 256 MiB просмотренных tar members,
20 MiB на сохранённый файл. Только шесть normal/abnormal metrics/sum/traces;
oracle/log/conclusion/injection/env не читаются. Извлечение по basename в наш
каталог, без исполнения кода и tar extractall. Этот datapack DISCOVERY_ONLY.

Пин кода формата: OperationsPAI/rcabench-platform
`a14339077215690d895305e8898201ca6683cad8`.
`docs/specifications.md` прямо задаёт duration nanoseconds. Код
`v2/sources/rcabench.py` при конверсии выбирает лишь часть Attributes;
на raw нужно проверить direction/interface, Unit и temporality.
Установленная единица из источника исправляет прежнюю неопределённость,
но не восстанавливает потерянные измерения облегчённых таблиц.

Полное скачивание допустимо при полезном raw-формате; сохранить один сжатый
архив с проверкой размера/MD5, распаковывать только нужный срез. Остановиться
при свободном месте <30 GiB. Не менять среду продукта и не публиковать raw.

## Второй gate: до модели

Если исходный формат пригоден — loss-aware adapter: единицы, counter reset,
истинная идентичность ряда, inventory, временные границы и missingness.
Unknown не равен нулю; дополнительные сигналы не выдаются за данные обучения
замороженной модели. Старые три ops-lite случая, raw discovery и любые их
дубликаты исключить из будущего теста.

После schema discovery зарегистрировать точный срез/split/группы, один matched
опыт узкого против расширенного входа, простую эвристику и frozen champion.
Приоритет — независимые RED и ресурсное насыщение при полных/неполных traces.
Нельзя заранее обещать прирост или считать tree gain доказательством пользы.
До отдельного экспериментального протокола ranking fits/inferences = 0.

Если raw не подходит — выбрать другой источник по контракту; не скачивать
другие зеркала той же записи как «новую систему» и не переобучать M14.
