# Уточнение размерности R3

19.10.2026. Контроль перед augmentation выявил ошибку старого handoff:
в нём указаны 63 признака, фактический sealed M13 содержит **62** —
59 диагностических и 3 признака исходного рейтинга. Это подтверждено
freeze-manifest и feature_names сохранённой контрольной модели.

R3 temporal-screening фактически использовал правильные 62 и 72 столбца:
код берёт FEATURES + RANKING_FEATURES, не константу из prose. Его результат
не меняется; ошибочно только словесное число в регистрации-протоколе.
Первоначальные протоколы не переписываются после результатов; это отдельная
явная поправка. Веса, код признаков и схема продукта не изменяются.

Первый запуск missingness (`r3-ml-missingness-v1`) остановлен assertion
len(columns)==63 **до извлечения masked features, fit и inference**.
Новых ranking fits в этой попытке ноль. Повтор технической подготовки —
`r3-ml-missingness-v2`, тот же протокол и критерии, но проверка фактической
схемы freeze вместо неверного литерала. Это не повтор ради лучшего результата.
