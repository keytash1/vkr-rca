# R3-B — диагностика нагрузки и неполноты

19.10.2026. Дополнение зарегистрировано после отрицательного temporal-screening,
до расчёта результатов этих контролей. Не новый поиск конфигурации по лучшей
метрике и не повтор предыдущего опыта. Дополнительных ranking fits — ноль.

Проверяются два оставшихся механизма из handoff:

1. Насколько вывод frozen champion чувствителен к здоровой опоре другого
   режима нагрузки. Сравнить принятую опору с отдельными healthy-only low и
   high опорами. Строятся две новые исследовательские калибровки, веса не
   меняются; исходные параметры не перезаписываются. При одном RPS оценка
   константная/медианная, это не выученный диапазон интерполяции.
2. Как меняется рейтинг при полном отсутствии спанов и отличает ли именно
   численная модель успешное пустое чтение от отказа источника. Это не
   испытание реального Jaeger и не модель всех режимов sampling. Обязательное
   различение статусов в evidence/API сохраняется независимо от rank.

Выбор: по одному кластеру на каждую пару fault_family/workload_regime,
детерминированно по SHA группы с seed 20261019, оба повтора. Всего 20 случаев,
выбранных без просмотра их рангов. Корпус USED_DEVELOPMENT; модель обучена
на нём, поэтому качество справочное in-sample и не доказывает перенос.

Пять условий на каждый случай: исходное, healthy-low, healthy-high,
traces-empty/collected=True, traces-empty/collected=False. Всего 100 inference,
до 5 минут. Две новые healthy preprocessing builds (число отдельных каналов
и наличие Huber-fit записать); ranking fits, LLM, Docker и загрузки — ноль.

Сохранить по условиям ранги, смену первого кандидата, сдвиг MRR/AC для
описания чувствительности, разбивку по нагрузке и различие масок источника.
Не выбирать лучшую опору по этим результатам для продукта. Возможный итог —
подтверждение необходимости уже имеющихся оговорок/явной калибровки либо
конкретный дефект для отдельного исправления; не автоматическое улучшение ML.

Граничные timestamps M13 дополнительно описать по исходному коллектору:
metric timestamps округлялись вниз до целой секунды, а Jaeger может вернуть
спаны вне окна как часть полной трассы. Не «чинить» старый корпус задним числом.
Проверить фактическую величину граничного сдвига, а не объявлять утечку только
по сравнению float-границ. Для нового сбора сохранять исходные дробные времена.
